🎙️ Справка: Развёртывание офлайн-озвучки для тренажёра «Читай-ка»

Полное пошаговое руководство по переносу системы генерации звуков слогов и слов на любой компьютер с Windows с нуля. Голоса генерируются локально через нейросеть Silero TTS (голос Бая) и сохраняются в формате WAV.

⚙️ Движок: Silero TTS v4 (RU) 👩 Голос: Бая (baya, 24 кГц) 💰 Стоимость: 0 ₽ (локально, без интернета после загрузки) 🚀 Запуск: по кнопке start.bat
ФИНАЛЬНАЯ СТРУКТУРА

Как должна выглядеть рабочая папка проекта

Все файлы системы должны находиться в одной общей папке (например, C:\Chitayka\):

📁 Папка проекта/
├── 📄 Chitayka.html       (ваш основной тренажер для ребенка)
├── 📝 Words.txt           (блокнот со списком слогов и слов)
├── 🐍 generate_words.py  (скрипт синтеза речи на Python)
├── ⚡ start.bat           (файл запуска генерации в один клик)
└── 📁 audio/              (папка с готовыми .wav файлами, создается скриптом)
    ├── 🎵 БА.wav
    ├── 🎵 КО.wav
    ├── 🎵 КОТ.wav
    └── 🎵 МА-МА.wav

  1. Перейдите на официальный сайт и скачайте свежий установщик Python для Windows:
    Скачать Python с python.org ↗
  2. Запустите скачанный файл инсталлятора python-3.x.x.exe.
⚠️ КРИТИЧЕСКИ ВАЖНО: В самом первом окне установщика внизу обязательно поставьте галочку:

☑ Add python.exe to PATH

Если эту галочку не поставить, Windows выдаст ошибку «Имя "pip" / "python" не распознано как имя командлета». После установки перезапустите окно терминала.
ШАГ 2 ИЗ 5

Установка библиотек в командной строке

Откройте Командную строку (нажмите Win + R, введите cmd и нажмите Enter). Скопируйте и выполните команду:

pip install torch torchaudio soundfile omegaconf

Зачем нужен каждый компонент:

  • torch & torchaudio: базовый движок нейросетей PyTorch для работы модели Silero.
  • soundfile: библиотека для сохранения звука напрямую в файлы формата WAV без старых зависимостей вроде pydub/audioop (которые были удалены из Python 3.13+).
  • omegaconf: библиотека конфигурации параметров речи, необходимая движку Silero TTS.
ШАГ 3 ИЗ 5

Создание файлов скрипта и запуска

1. Файл Words.txt

Создайте текстовый документ Words.txt и впишите нужные слова и слоги по одному на строку:

БА БО БУ КО ДЕ ЖИ КОТ ДОМ МА-МА СОБАКА
💡 Подсказка по ударениям: Для редких или двусмысленных слов знак плюса ставится перед ударной гласной (например, з+амок или зам+ок). Для прямых двухбуквенных слогов вроде КО или БУ скрипт расставит ударения автоматически.

2. Файл generate_words.py

Создайте файл generate_words.py через Блокнот и сохраните следующий код:

import os import sys import ssl import torch import soundfile as sf # Обход проверки SSL-сертификатов при загрузке модели ssl._create_default_https_context = ssl._create_unverified_context WORDS_FILE = "Words.txt" AUDIO_DIR = "audio" VOICE = "baya" SAMPLE_RATE = 24000 VOWELS_SET = set("аоуэыяеёию") def prepare_text_and_stress(raw_word): clean = raw_word.strip() spoken_text = clean.replace("-", "").replace("–", "").lower() # 1. Если знак плюса уже стоит вручную if "+" in spoken_text: return spoken_text, False # 2. Прямой слог из 2 букв (КО, БУ, ДЕ) — ставим ударение принудительно (к+о, б+у) if len(spoken_text) == 2 and spoken_text[1] in VOWELS_SET: return f"{spoken_text[0]}+{spoken_text[1]}", False # 3. Обратный слог из 2 букв (УН, АМ, ОС) — ставим ударение (+ун, +ам) if len(spoken_text) == 2 and spoken_text[0] in VOWELS_SET: return f"+{spoken_text[0]}{spoken_text[1]}", False # 4. Длинные слова — нейросеть сама ставит правильное ударение return spoken_text, True def main(): print("=" * 60) print(" Генератор озвучки слогов и слов (Silero TTS - Baya)") print("=" * 60) if not os.path.exists(WORDS_FILE): print(f"Файл {WORDS_FILE} не найден. Создаю новый файл...") with open(WORDS_FILE, "w", encoding="utf-8") as f: f.write("БА\nБО\nБУ\nКОТ\nДОМ\nМА-МА\n") words = [] with open(WORDS_FILE, "r", encoding="utf-8") as f: for line in f: line = line.strip() if line and not line.startswith("#"): words.append(line) if not words: print(f"В файле {WORDS_FILE} нет слов для озвучки!") return print(f"Слов/слогов в очереди: {len(words)}") os.makedirs(AUDIO_DIR, exist_ok=True) print("Загрузка русской нейросети Silero TTS (голос: Бая)...") device = torch.device("cpu") torch.set_num_threads(4) model, _ = torch.hub.load( repo_or_dir="snakers4/silero-models", model="silero_tts", language="ru", speaker="v4_ru", trust_repo=True ) model.to(device) print("\nНачинаем генерацию...") success_count = 0 for i, word in enumerate(words, start=1): phrase, auto_accent = prepare_text_and_stress(word) clean_name = word.replace("-", "").replace("–", "").strip().upper() main_filename = os.path.join(AUDIO_DIR, f"{clean_name}.wav") try: audio = model.apply_tts( text=phrase, speaker=VOICE, sample_rate=SAMPLE_RATE, put_accent=auto_accent ) sf.write(main_filename, audio.numpy(), SAMPLE_RATE, format="WAV") # Для слов с дефисом создаем копию с дефисом для точного совпадения if "-" in word or "–" in word: hyphen_filename = os.path.join(AUDIO_DIR, f"{word.strip().upper()}.wav") sf.write(hyphen_filename, audio.numpy(), SAMPLE_RATE, format="WAV") print(f"[{i}/{len(words)}] Озвучено: {word} -> {main_filename}") success_count += 1 except Exception as e: print(f"[{i}/{len(words)}] Ошибка в слове '{word}': {e}") print("\n" + "=" * 60) print(f"ГОТОВО! Создано {success_count} аудиофайлов в папке '{AUDIO_DIR}/'") print("=" * 60) if __name__ == "__main__": main()

Подключение к странице Chitayka.html

В файле Chitayka.html в блоке <script> должны присутствовать следующие элементы:

1. Функция воспроизведения:

let currentAudio = null; function speakCurrentSyllable() { if (!currentText) return; // Очищаем от дефисов и пробелов: "МА-МА" -> "МАМА", "ко" -> "КО" const cleanKey = currentText.replace(/[-–\s]/g, '').toUpperCase(); if (currentAudio) { currentAudio.pause(); currentAudio.currentTime = 0; } currentAudio = new Audio(`audio/${cleanKey}.wav`); currentAudio.play().catch(err => { console.warn(`Файл audio/${cleanKey}.wav не найден:`, err); }); }

window.addEventListener('keydown', (e) => { // Нажатие СТРЕЛКИ ВВЕРХ или СТРЕЛКИ ВНИЗ — озвучить текущую карточку if (e.code === 'ArrowUp' || e.code === 'ArrowDown') { e.preventDefault(); speakCurrentSyllable(); return; } // Стрелки Влево/Вправо и Пробел листают карточки дальше if (e.code === 'ArrowLeft') { e.preventDefault(); if (e.repeat) return; prevCard(); } else if (e.code === 'Space' || e.code === 'ArrowRight') { e.preventDefault(); if (e.repeat) return; nextCard(); } });

Решение возможных проблем при переносе

1. «Имя "pip" не распознано как имя командлета»

Причина: При установке Python не была включена галочка «Add Python to PATH».

Решение: Переустановите Python, обязательно отметив эту галочку, либо запустите установку библиотек через системный лаунчер: py -m pip install torch torchaudio soundfile omegaconf.

2. «The repository snakers4_silero-models does not belong to the list of trusted repositories (y/N)?»

Решение: В коде скрипта уже добавлен параметр trust_repo=True, поэтому модель загрузится автоматически без вопросов безопасности в консоли.

3. «SSLCertVerificationError: certificate verify failed»

Причина: Несовпадение даты на компьютере либо отсутствие корневых сертификатов в Windows.

Решение: В скрипт уже включена директива ssl._create_default_https_context = ssl._create_unverified_context, которая предотвращает сбои проверки сертификатов при загрузке модели.

🎉 Итог: Для добавления новых слов достаточно открыть Words.txt, вписать слова и запустить start.bat. Все файлы появятся в папке audio/, а страница Chitayka.html сразу воспроизведёт их по нажатию клавиш со стрелками.
